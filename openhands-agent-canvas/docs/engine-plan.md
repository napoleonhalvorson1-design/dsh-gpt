# 接入引擎升级

目标：同一个私有插件可配置接入 AI、S3、GitHub、网盘及其他 HTTP API，并由 Codex 聊天操作。

验收要求：
- 连接注册表，类型与操作目录，环境变量/加密凭据，可测试/禁用/更新并校验版本。
- 既有五个 AI 入口、既有七彩云桶直接可用；新增 OpenAI 兼容模型、Anthropic、S3、GitHub、WebDAV、Google Drive、OneDrive、HTTP/OpenAPI 连接器。
- 通用调用后台执行，持久化状态、结果、错误，重试使用同一个 ID 不重复发送；服务恢复不自动重放外部写操作。
- 多步骤流程串联连接器，支持输入与上一步结果引用，保存/运行/查看，保持既有五 AI 项目和数据。
- 网站中文连接管理与手机查看，MCP/CLI 提供同一引擎，发布既有插件、网站和服务器服务。
- 验证鉴权、读写权限、凭据保护、路径/重定向/响应限制、分页、幂等、重启、真实只读接入；未提供授权的外部账号不能报已连接。
